# Native respiratory pressure-source work observer

This increment observes the existing native respiratory circuit. It does not create a diaphragm or rib degree of freedom, apply IBM neural output, transfer chest recoil ownership, or add respiratory work to the signed skeletal-muscle metabolic port. The current physical-loop gap remains as documented in [the respiratory ownership audit](RESPIRATORY_MECHANICAL_PORT_AUDIT.md).

## Source-bound decomposition

Held BioGears revision `3f16a5fa1dade9c511b88d923606fa51cc35e95d` defines `EnvironmentToRespiratoryMuscle` as an ideal pressure source from the ambient reference node to the volume-less respiratory-muscle node (`BioGears.cpp:4780`). Its other two incident paths are `LeftPleuralCavityToRespiratoryMuscle` and `RightPleuralCavityToRespiratoryMuscle`, each a chest compliance (`4788–4791`). Separate bronchi/alveoli-to-pleural-connection compliances supply lung recoil. The pleural connection nodes deliberately have no volume; they prevent lung compliances from changing pleural-node volume directly (`4697`, `4749`). The observer requires the three-path muscle-node topology and ordinary positive, nonpolarized chest compliance. It rejects an unrecognized additional muscle boundary or constitutive element.

The actual pressure-source potential is `P = Ptarget − Psource`, and its flow `Q` is positive from source to target (`SECircuitCalculator.inl:346–362`, `527–536`). The circuit source supplies interval work

`Wsource = Papplied,next * Qsource,next * dt`.

This is the native solver's endpoint effort/flux product over its discrete interval. It is not an exact continuous-time integral. Positive work is delivered into the rest of the circuit. Define source stroke `S = −Qsource,next*dt`; the muscle-node Kirchhoff identity is `Qsource*dt + Sleft_chest + Sright_chest = 0`. Generated and external components use the **same actual solved source flow**: `Wgenerated=Pgenerated*Qsource*dt`, `Wexternal=Pexternal*Qsource*dt`, whose sum is `Wsource`. The generated component is ideal-source work, not measured muscle-fiber work or chemical energy.

Total lung volume is separately observed. The existing adapter value `−Pexternal*ΔVlung` is retained as an explicitly labeled proxy in the new receipt, together with its difference from source-flow work. Equality is tested in a closed isolated fixture, not assumed for a full patient with pleural leaks, altered topology, gas handling, or other volume owners. The source stroke is not added to lung volume as a second store.

For each chest path, `p=Ppleural−Pmuscle`, `S=Qnext*dt`, and the native constitutive equation is `S=Cnext*pnext−Ccurrent*pcurrent` (`SECircuitCalculator.inl:564–579`). Its endpoint branch work is `pnext*S`. The diagnostic quadratic compliance storage change is `ΔE=½(Cnext*pnext²−Ccurrent*pcurrent²)`. Their residual is retained separately. For constant C this residual is `½*C*(pnext−pcurrent)²`, the endpoint discretization term; when C changes it also contains constitutive-parameter work. It is **not physical heat**, and the observer writes no thermal source or native energy store. It does not claim a closed whole-circuit energy balance because airway resistance, lung compliance, other sources and physiological gas transfer are outside this narrow ledger.

## Timing and ownership

`BioGears::PreProcess()` calls Respiratory before Nervous (`BioGears.cpp:971–987`). `RespiratoryDriver()` samples requested amplitude/frequency only at cycle rollover, computes the waveform and sets the next pressure source (`Respiratory.cpp:817–913`). Nervous subsequently updates requested amplitude/frequency (`Nervous.cpp:913–919`). Therefore a request observed after all PreProcess calls can describe a later breath; it must not be mislabeled as the request that generated this interval. The precise applied waveform is the pressure-source value captured after native respiratory PreProcess and before the adapter's sole external-pressure modifier.

`WorkObserver.begin(circuit,tick,dt,generated,external,lung_before)` runs after PreProcess and the modifier, before Process; it binds the actual pressure sum and current chest effort/compliance plus next compliance. `solved(circuit,lung_after)` reads native NEXT pressure/flow values after Process and before PostProcess resets next baselines (`SECircuitCalculator.inl:839–852`). Its lung argument must be solved native volume, not stale current node volume. The native respiratory system calculates its volume output during Process, before all other systems have completed; any future integration must retain and label that timing explicitly.

`commit(tick+1)` publishes only after the entire native interval succeeds, including signed-muscle `finish` when active. Calling `fail()` prevents receipt publication and retry. A solved candidate cannot be published before commit. This is receipt staging, **not whole-engine rollback**. Physiology may already have consumed a meal or changed irreversible state when a later system fails; the native process must remain terminal. No repeated physiology advances are permitted to solve a respiratory fixed point.

The helper is read-only. Native ideal drive, airway/gas transport and both passive chest/lung recoil remain native-owned. A future physical thorax must explicitly replace the ideal-source and overlapping chest-compliance roles and partition its mass from the existing torso before any mechanical actuator work can be credited. This observer neither approves nor implements such a replacement.

## Bounded fixture and next integration

`verify_native_respiratory_work.py` defaults to source preparation only and checks held source bytes against Git. Explicit `--compile-and-run` links the immutable GI variant, verifies source/circuit objects and loaded library, and retains build/run resources. The fixture constructs two airway-resistance/lung-compliance/chest-compliance branches using the real native circuit calculator. It performs no patient initialization or gas chemistry. It checks source-work partition, source-flow KCL, constitutive residual, compliance-storage discretization, changing compliance, observed/unobserved solver parity, and commit/failure sequencing. It does not establish full-patient waveform, gas-volume or shared-adapter acceptance.

The next bounded integration is an isolated whole-engine observer probe with source-generated original advance ordering: capture generated waveform after PreProcess; observe the solved circuit before PostProcess; publish only after the successful native return and signed finish. Pair observed and unobserved frozen-state short runs at zero external load, then a small load pulse; retain drive, source flow, bilateral chest variables, total lung volume, and explicit source-versus-lung stroke residual. Shared adapters and existing work fields remain unchanged until that evidence is reviewed. Full-patient tracing must separately label pre-waveform demand and post-Nervous demand, rather than attributing the latter retroactively.
