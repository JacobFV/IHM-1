# Native nervous sleep state correction

This source correction addresses the continuation defect exposed by the [whole-engine respiratory probe](NATIVE_RESPIRATORY_ENGINE_ACCEPTANCE.md). Original BioGears sources, generated bindings, objects and libraries remain immutable. The correction requires a separately built engine **and matching CDM schema library**; it cannot be installed as a header-only change or linked against the old CDM ABI.

## Owner and lifecycle audit

| State | Native behavior | Continuation defect and correction |
|---|---|---|
| Private `m_AttentionLapses` | Initialize 3; copied from public scalar at each sleep calculation; native marshaller writes private mirror | Constructor/load leave private value undefined before first Process. Restore exact owner plus public mirror. |
| Private `m_BiologicalDebt` | Initialize 0; updated by native debt ODE; copied from public scalar at calculation entry | SetUp resets private debt to 0 after public scalar load; save before Process can overwrite loaded debt. Remove this state reset from SetUp and restore after LoadState. |
| Private `m_ReactionTime_s` | Initialize .3 and public .3 s; later constants 300/16.67 act as milliseconds; final output divides private value by 1000 | Private value absent from schema/load; uninitialized read on common branch. Keep private field in seconds consistently: intercept .3 s, slope .01667 s/tired-hour, no final /1000. This also fixes the fresh .3 s → .0003 s jump. |
| Private `m_TiredTime_hr` | Initialize 0; increments by dt/3600 only when awake wake/sleep ratio exceeds 3 | Entire history absent from schema/load. Serialize exactly; never infer from current public outputs or substitute zero during load. |
| Public wake/sleep clocks | Minutes; updated and reused each native sleep calculation | Include exact clocks in versioned snapshot because ordinary XML double formatting is not lossless. |
| Public sleep mode | Native Awake/Sleeping enum, fresh initializer Awake; native sleep action updates it | Preserve explicit mode with versioned owner snapshot and reject disagreement with public XML. |

`Nervous` constructor calls Invalidate, which previously set pointer members only. Corrected Invalidate assigns NaN sentinels to all four private sleep fields. Save and sleep calculation reject uninitialized/nonfinite state. `Initialize()` retains explicit **new, fresh-rested initialization**: attention 3, biological debt 0, reaction .3 seconds, tired history 0 hours, wake time 0 minutes, sleep time from the patient's configured sleep amount, mode Awake. These are model initialization assumptions, not restoration of any existing patient's history.

Native `CalculateSleepEffects()` refreshes attention/debt from public scalars before calculation, but reaction time and tired time do not have such restoration. The native recovery branch resets reaction/lapse outputs without resetting tired history; public outputs therefore do not uniquely identify the private accumulator. Its `count` is a local value reset to 1 every call, so incrementing it retains no recovery history. The recovery comparison also mixes a dimensionless wake/sleep ratio with minute quantities. These broader native-model limitations are recorded; this serialization/unit correction does not invent a revised sleep/recovery model or claim clinical calibration of its ODE constants.

## Exact versioned representation

`native_nervous_sleep_state.h` defines one `IHM_SLEEP_V1` payload: Awake/Sleeping plus six IEEE-754 binary64 values, in declared order: attention lapses, biological debt, reaction seconds, tired hours, wake minutes, sleep minutes. Each double uses 16 canonical lowercase hex digits for its numerical bit pattern. The wire representation is endian independent. Finite/nonnegative values are required; reaction time and sleep-time denominator must be positive. Unsupported version, malformed length/separators/hex, unknown mode, negative/nonfinite values, and uninitialized state fail.

The held CodeSynthesis header `xsd/cxx/tree/serialization/double.hxx:50` defaults to `numeric_limits<double>::digits10` (15). Neither held compile flags nor the schema options set its maximum-precision macro. For example, `nextafter(3,4)` is written as `3` with 15 significant digits. The exact hex representation avoids silently losing private history while preserving the existing serializer for unrelated physiology. It does **not** make the rest of native state serialization lossless.

The optional XSD `IHMSleepState` string preserves schema parsing of legacy input so the corrected native loader can issue an explicit rejection. It is mandatory for corrected native continuation. The decoder checks it before invalidating the Nervous owner. After base unmarshalling and native SetUp, it checks public XML mirrors against the exact payload, accepting only exact equality or the held serializer's precise 15-digit formatting roundtrip. No arbitrary tolerance is used. It then restores all private fields and public clocks/outputs from the exact owner payload. The encoder validates initialized state and exact public/private consistency before writing. The full physiology loader may already have touched other systems before reaching Nervous; this rejection is not whole-engine transactional rollback.

`prepare_native_nervous_sleep_patch.py` emits isolated patches for inherited signed Nervous.cpp, native BiogearsPhysiology.cpp and BioGearsPhysiology.xsd. It retains source Git equality, the signed source manifest and parent object/library lineage. No basal/stress, signed muscle, respiratory waveform, chemical or thermal owner is replaced.

## Legacy input policy

Legacy tired history is irrecoverable from these files alone. Ordinary LoadState rejects missing versioned sleep state. For an intentionally new sleep initialization on retained nonsleep physiology, `--seed-legacy` requires a JSON document with exactly: schema `ihm.explicit-native-sleep-initialization.v1`, nonempty provenance, all six numerical fields, and `sleep_state` (`Awake` or `Sleeping`). There are no numerical defaults. The tool writes a **new** state path and an adjacent initialization receipt with original/output hashes and all supplied assumptions. It refuses existing output/receipt paths, incomplete values and already versioned sleep states. This is an explicit new sleep epoch, never advertised as historical recovery. The generated state remains unverified until the corrected native schema/variant accepts it.

The tool changes only the named sleep fields and appends their versioned snapshot; other XML owners remain present. It preserves lexical namespace bindings used in xsi:type, rejects prefix rebinding it cannot safely migrate, and reparses output before writing. Tests preserve nonsleep fields and verify prefixed type output parses successfully.
