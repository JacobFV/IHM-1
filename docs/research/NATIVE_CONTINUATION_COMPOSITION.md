# Native continuation composition

The new isolated variant combines accepted sleep persistence, GI serialization/ownership, cardiovascular circuit-region metadata, and Tissue burn history. Original libraries, states, prior receipts and default runtime selection remain unchanged. The acceptance target is actual native save/reload followed by the next tick, with every observed mismatch retained.

## Source and ABI plan

The parent is `whole_body_integrity_nervous_sleep_v1`, manifest SHA-256 `245de131d8ff022c33b46c12cf62ff510fd1fbc7b8aee36a6b225a604f2ab94a`, with its paired CDM/generated/schema family. Accepted GI fixes are from `gi-codec-full-tu-3juo1cj5/objects_manifest.json`; their outer serializer method is composed into the parent's already-corrected native IO source. The shared `io/biogears/BioGearsPhysiology.cpp` is compiled once with sleep, GI and Tissue changes together.

The GI history marker is `GITransitInventoryVersion`, optional `xs:unsignedInt` in schema but required to equal 1 by the corrected native loader. An owner boolean starts false, clears on invalidation, and becomes true only after native fresh initialization or complete marked load. Serialization rejects an unknown owner. This distinguishes an authoritative empty inventory from an old omitted inventory without inventing drug mass. The original isolated three-TU GI receipts retain their narrower scope.

The GI owner field changes native class layout. The final prepared `whole_body_integrity_continuation_v3` therefore rebuilds the exact union of 30 native Gastrointestinal-header consumers, 9 changed-schema core consumers, and the distinct GI ownership/nested-IO/Circuit source corrections: **35 core plus 3 CDM objects**. The other 325 core and 32 CDM objects are inherited exactly. Both the regenerated schema include directory and patched native header directory precede original include paths. No pre-sleep or old-GI-layout object is reused where its dependency requires rebuilding.

All affected donor sources are recovered from the actual inherited object's accepted source identity. This preserves signed Energy/Cardiovascular/Endocrine, sleep Nervous, GI absorption, shared-donor Diffusion, humidity Environment, Renal and Saturation corrections while recompiling them for the new header. It does not replace them with raw upstream source. Every job records original object identity, actual source, compiler command, generated bindings and input hashes. Preparation pins 1,392 external inputs plus frozen copied sources/headers/schema. Compiler/linker stages check these inputs and inherited objects; paired output libraries are new files.

`build_native_continuation_variant.py` has separate prepare, codegen, indexed compile and link stages. Codegen and native stages require the shared resource grant. The initial 16-job v1 preparation is retained, uncompiled, before the GI presence/layout requirement. A v2 source-only preparation failure is retained: Environment has both native-system and IO object basenames. The v3 resolver distinguishes the actual inherited native override, and source tests verify preserved donor bytes.

## Explicit initial conditions and failures

`verify_native_continuation_source.initialized_state` prepares a new copied experiment state with complete receipts: source-pinned circuit metadata reconstruction for the exact 348-path graph, new rested-awake sleep values using actual patient SleepAmount, explicitly declared no-prior-burn/escharotomy history, and explicitly declared empty oral-drug history. Each transformation retains hashes and provenance. Absence of old history is never treated as evidence that it was zero. Existing burn markers, oral-dose/transit records, or already-versioned owners prevent the corresponding fresh initializer from overwriting history.

Corrected native continuation must reject missing/unsupported sleep, burn and GI markers. Failed load or calculation owners are not retried or reported as accepted; full-engine rollback is not claimed.

## Verification stages

Five lightweight tests pass for complete layout dependency coverage, shared IO/schema composition, preservation of inherited corrections, complete explicit initializations and changed-input rejection. No composed native job has run yet.

Next stages are bounded schema generation, separately granted compile chunks and paired link; actual native owner tests including GI unknown-owner/partial-decode rejection and all Tissue histories; then public paired-DSO control/save/reload/next-tick experiments. GI and Tissue owners supply observation/assertion headers; this lane owns the combined orchestration and provenance.

The native serializer still emits ordinary doubles with 15 significant digits. The new exact sleep/burn payloads do not make all other runtime scalars lossless. Acceptance must distinguish all-field XML equality from exact runtime scalar roundtrip and preserve precision or lifecycle failures. No fields or numerical differences will be removed, and no global formatting macro will be mixed into only some translation units. Any broader repair follows measured evidence from the strict composed test.
