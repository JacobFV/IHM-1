# Full-engine regional Skin acceptance

The standalone `native_regional_skin_engine_probe.cpp` loads the exact retained
stabilized native state used by the signed/GI smoke tests. It runs the native
engine's held `AdvanceModelTime(bool)` implementation, generated byte-for-byte with
only regional hooks after PreProcess and PostProcess. Native event updates,
configuration timestep, clocks and tracking scheduling remain intact. No production
adapter is edited, and this probe does not run fresh patient stabilization.

## First full-engine failure retained

`data/derived/audits/native-regional-engine-0tzsmrn9` contains the complete baseline
12-step run, successful regional installation/initial ownership snapshot and a
failure on the first regional native step: `Scalar is marked read-only`.
A gdb catch-throw isolated the call chain:

`SEScalarQuantity<MassUnit>::IncrementValue` → `Energy::CalculateSweatRate` →
`Energy::PreProcess` → native `BioGears::PreProcess`.

`diagnosis.json` is a summary of that observed stack, not a substituted execution
transcript. This failure occurred even at zero sweating because the source writes
an increment of zero directly to the three cached Skin ion masses. Those quantity
objects correctly became read-only aggregate views after the split.

## Native source correction

`native_regional_species.h` performs mass-weighted withdrawals on native owning
leaves and pairs them with the **existing native** cumulative Na/K/Cl sweat-loss
scalars. `build_biogears_regional_sweat_variant.py` creates a new immutable child of
`whole_body_integrity_regional_skin_gi_v1`, replacing only the inherited signed
Energy object. The patch replaces exactly three adjacent donor/waste statement
pairs. All sweat-rate calculations, ionic concentrations, water-density conversion,
patient mass loss, subsequent Balance calls, flow-source updates and signed muscle
logic remain unchanged. Unsplit owners use their original direct debit path.

The helper validates requests and all leaf budgets before withdrawal, rejects
overspending without donor or waste mutation, and handles exact donor depletion.
It never clears read-only flags on aggregate masses. Its small exported ledger is
an observation record, not an extra waste store. The paired donor and native-waste
mass residual and transported ionic charge are observable. The native sweat model
uses 51/6/48 mM Na/K/Cl; its selected ionic subset is not electroneutral. The ledger
checks matching donor/waste charge, not fabricated neutralizing ions.

## Bounded acceptance gates

`verify_regional_sweat_source.py` verifies that reversing the three paired native
sweat substitutions restores inherited Energy source exactly, and that removing
the two regional hooks restores the held native lifecycle method exactly.

The native sweat fixture exercises actual native liquid compartments/substances,
three owning leaves and native mass scalars for partial withdrawal, zero withdrawal,
rejected overdraw and exact depletion for each ion. It checks matched donor/waste
mass and charge and the parent's read-only aggregate status.

`verify_native_regional_skin_engine.py --run` compiles standalone probes and runs
matched baseline, regional zero-load and regional local-load/unload modes, 12 native
steps of 0.02 s each. It records all common native observations, unavailable old
active-circuit observer ports, aggregate/leaf species mass residuals, per-region and
parent fluid-incidence residuals, and the native sweat ledger. A 133.3224 Pa local
load is applied only in region_a at steps 6–7 and removed at step 8. Source graph
regions remain engineering allocations, and regional chemical independence or
whole-body species closure is not asserted.

Compilation and execution require the root's one-process native slot. The probe
caps compilers at 1 GiB/60 s CPU and native state-load runs at 2 GiB/30 s CPU/40 s
wall per mode. All failed artifacts are retained. A completed isolated native
library alone does not satisfy these acceptance gates.

## Second full-engine failure and graph correction

`data/derived/audits/native-regional-engine-__r81tpf` retains the corrected native
sweat fixture and full baseline, followed by the regional failure in native
Cardiovascular Process. Gdb identified a read-only concentration write in
`SESubstanceTransporter::Transport`. Native BioGears.cpp explicitly adds tissue
compartments to the cardiovascular liquid graph **without links**. Updating only
compartment owning-leaf caches left the aggregate parent in that transport graph.

The header now preflights all affected graphs for absent parent links, replaces
each aggregate vertex with the three owning leaves, and refreshes graph state.
Unexpected links fail closed before surgery. The full probe asserts the parent is
absent from all native transporter graphs after installation and at every output.
No transport concentrations are made writable on aggregate quantities.
