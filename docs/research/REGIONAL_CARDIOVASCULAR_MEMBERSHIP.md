# Regional skin cardiovascular membership

The accepted `whole_body_integrity_regional_skin_graph_v2` does not clone the vascular Skin resistance paths. It clones nine extracellular/lymph/sweat laws into three regions, creating 27 paths plus three external-pressure drives. Only six cloned paths have resistance baselines: the three copies of `SkinE1ToSkinE2` (capillary filtration) and three copies of `SkinL1ToSkinL2` (lymph drainage). None of their nine original path laws receives a cardiovascular region in the pinned native controller.

`Aorta1ToSkin1` and `Skin1ToSkin2` remain active and unsplit. Both receive `Extrasplanchnic` in the native constructor. The existing-field IO repair restores those labels before `Cardiovascular::SetUp` builds its routine resistance caches. These two vascular paths can therefore respond to native nervous feedback and the isolated experimental vascular prior. Adding Extrasplanchnic labels to filtration/lymph clones would be a new physiological classification, not a repair of lost source metadata; no such patch is made.

The current `copy_laws` does omit metadata, but all nine source labels are intentionally absent under this exact source topology. The configured regional header changes class name, region names/fractions, and a provenance constant, while preserving the same path inventory and law-copy implementation. A future vascular split must separately define control ownership and cache membership; merely adding metadata copying is insufficient.

Setup ordering matters. The adapter first loads native state, which performs system SetUp, and then installs the split. Native tissue law pointers therefore retain detached original objects. `RemovePath` removes originals from the active circuit without deleting those objects. After native PreProcess, `after_preprocess` copies updated original laws into regional paths (resistance divided by regional fraction); after native PostProcess it mirrors committed laws and summed flows into detached originals. Skin capillary resistance also belongs to the explicit `m_tissueResistancePaths` tuning list, distinct from the region-tagged routine vascular list. Re-running cardiovascular SetUp after removing those named original paths would invalidate this contract and is not part of the proposed composition.

`audit_regional_cardiovascular_membership.py` verifies exact source/header/state identities and emits all 27 cloned path names, both retained vascular members, and the three pressure-drive names. Three light tests cover membership, retained law ownership, and preservation of regional object owners during preparation. These are source/topology findings, not a native response result.

`prepare_regional_cardiovascular_experiment.py` stages an isolated baseline/reader/prior experiment. Each recipe preserves 358 graph_v2 objects and replaces exactly Circuit IO and Cardiovascular with verified donor objects. It retains graph_v2's Diffusion and Energy objects, the two object differences relative to the GI baseline. The generated probe uses the existing regional lifecycle, records all new paths plus the retained vascular Skin paths, and reports regional volume/species/flow ownership outputs. No current shared adapter, default library, or header is modified.

The prepared composition supports only the exact existing graph_v2/CDM identities. Sleep adds generated-schema ABI dependencies, so its rebuilt Cardiovascular and Energy objects cannot be overwritten by these older objects. A later accepted composed branch must reapply the narrow reader/prior patch to its matching Cardiovascular source, preserve the region IO change, and merge regional sweat handling into the matching Energy source. GI and Tissue codec repairs remain independent required object owners. Their source/ABI inventories must be verified before composing; this preparation does not claim their fixes.

Pending native acceptance: use the same explicitly migrated state in all three regional variants; verify zero/inactive parity against the repaired regional baseline, the reader-only physical parity, retained Skin vascular resistance/flow response, and continued absence of invented labels on all tissue/lymph clones. Confirm finite clone flows, unchanged ownership bounds, and zero-demand modifier release. Configured fractions require their own named-configuration fixture and cannot inherit numerical acceptance merely from identical source algorithms. No regional native response has yet been measured in this increment.
