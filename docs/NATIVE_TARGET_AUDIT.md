# Native output versus upstream reference targets

`ihm.calibration.native_targets` compares actual native outputs with the 475 rows in `data/derived/physiology/validation_targets.jsonl`. These are literature values curated by upstream BioGears. Each row retains the original validation CSV path/hash, line, citation keys and bibliography-presence checks. They are not individual participant measurements, a matched validation cohort or proof that native coefficients have been calibrated locally.

Run `.venv/bin/python scripts/audit_native_targets.py` to write `data/derived/calibration/native-target-audit.json`. Run `.venv/bin/python scripts/verify_native_targets.py` for analytic parser, dimensional conversion, window-selection and binding checks.

The report includes the original 60-second fast run, the 180-second native baseline and completed `native_hour_*` runs. It selects samples strictly later than final timestamp minus 60 seconds. Thus a 50 Hz final minute contains 3000 observations, and a 1 Hz final minute contains 60. It reports arithmetic mean and observed minimum/maximum, not confidence intervals. Source CSV and configuration hashes bind each result to its run. Runs that have not reached their configured horizon appear under `skipped_runs`, rather than being labeled hour-long evidence. Distinct source engine variants remain separate; duplicated outputs are not pooled into independent evidence.

Bindings require exact native quantity names. For example, an unspecified `BloodPH` target is not silently rebound to `ArterialBloodPH`. Units must have explicitly supported matching dimensions. GFR of 125 mL/min equals 180 L/day; cardiac output of 5.6 L/min equals 5600 mL/min; kcal/day converts to watts using 4184 J/kcal and 86400 s/day. Celsius/Kelvin offsets are supported. Dimensionless quantities retain explicit dimensionless comparison units.

Only one finite scalar or one ordered bracketed numeric interval is parsed. The source strings `7.2, [7.35,7.4]`, `0.97, [0.96,1.0]`, and multiple respiratory-rate ranges remain intact rather than selecting a favorable reference. For points, the report gives mean minus target, its absolute magnitude, and signed difference divided by absolute target when meaningful. Relative differences are null for temperature, pH and zero targets. For intervals, it reports whether the observed mean lies within the source interval and signed distance to its nearest boundary; this is a descriptive comparison, not a clinical pass criterion.

All 475 target rows remain in every run audit. Current fast runs have 17 compared rows, two unparsed mapped targets and 456 unmapped quantities. Hour runs have 16 comparisons, with the mapped instantaneous total lung volume excluded because 1 Hz can alias breathing. Native arterial pulse output is likewise excluded if a matching target is present. Missing bindings and unavailable quantities do not disappear from the coverage counts.

The final minute of the original cool-room hour run has mean core temperature about 33.78°C, a signed difference of −3.22°C from the upstream 37°C point. Its GFR is approximately 180.15 L/day, versus the upstream 180 L/day point. These deviations describe different outputs of the same source experiment; neither licenses a global calibration claim. The 22°C / 0.5 clo environment and initial gastrointestinal water transfer contribute to long-run drift. Thermal interventions and engine variants must be interpreted using their attached configurations.

No tolerances, clinical pass/fail classifications, aggregate success percentages or optimized coefficients are created by this audit. A reference interval is not a confidence interval on the local simulation, and serial simulation samples are not independent human subjects.
