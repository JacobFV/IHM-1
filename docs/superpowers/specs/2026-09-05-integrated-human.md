# Integrated human implementation specification

User authorization: autonomous overnight implementation of remaining concerns, a 3D application, and IBM-inspired Laplace temporal spectra. Work proceeds without intermediate approval requests. Real evidence must never be replaced with fabricated calibrated coefficients.

The implementation preserves source-family identity while adding executable interfaces. Native BioGears provides integrated resting physiology, configurable native scenarios, state persistence and observation bindings. Explicit predictors include native simulation trajectories, empirical temporal models, and conservative spatial/compartment models. A source-grounded registry carries systems coverage, provenance, uncertainty, validity limits and unresolved identification gaps.

The spatial layer stores coordinate frames and validated transforms, landmark registration with residuals, physical dimensions, geometry hashes and specimen identity. Matching anatomy labels never establishes a transform. Bone, muscle and vascular assets remain selectable in original coherent families. Geometric preprocessing creates efficient multiresolution visualization assets, real muscle paths, flow arrows and time-resolved CFD playback where decoded source states exist. Display-only placement is labeled and separated from physiological registration.

The coupling layer uses signed conserved extensive exchanges with dimensional checks, mapping operators and recorded flux balance. It supports pressure/flow interfaces, vascular-interstitial-lymph exchange and skin extracellular transport without duplicating compartments. Parameter fitting retains bounds, identifiability diagnostics, holdout data, source and fitted residuals. Human wound experiments provide observational constraints rather than microscopic conductance identification. Missing paired lymphatic observations remain explicitly unidentifiable; code must support adding them.

Temporal representation follows IBM's actual implementation after inspection: finite Fourier bases and power-density evidence are distinguished from causal Laplace transfer functions and poles. Add cross spectra/coherence, finite-time complex Laplace transforms, stable reduced predictors with train/holdout errors, and resolvent responses for linear state models. Models preserve units, cadence, finite observation horizon, simulation-vs-measurement identity, and do not infer causation from coherence. Slow endocrine/immune behavior cannot be identified from a 60-second trace.

The local 3D app shows the real atlas, model-family selector, system layers, organ selection/search, source and calibration status, muscle paths, vascular pressure/velocity playback, physiology charts, spectral views and scenario controls. It must load efficiently and remain useful when optional assets/backend are unavailable. No remote publication is required. The app server binds localhost by default; file access is constrained to declared asset roots; scenario inputs are validated with bounded work and no shell interpolation.

Acceptance: existing checks remain green; meaningful new numerical tests cover conservation, transforms, spectra, parameter identification and native output validity; a real browser exercises the app and visualization controls; reproducible scripts regenerate inputs and outputs; documentation states exactly which mechanisms/observations are integrated and which biological unknowns remain.
