    MoBL-ARMS Dynamic Upper Limb
    This upper limb model is designed for use in dynamic simulation. Two versions are released for use in SIMM/SDFast and OpenSim. A new release compatible with OpenSim 3.2 and later is now available. See earlier release for the SIMM/SDFast model. Please see summary file and tutorials for more details about the model and changes from earlier releases.
    MoBL-ARMS dynamic upper limb model - OpenSim 4.1+
    Feb 22, 2021

    Dynamic unimanual upper limb model implemented for OpenSim software package, version 4.1 and later. Tutorial package includes output files for simulations in Version 3.3 and Version 4.1. See model summary file for additional details regarding changes from the earlier release, and for important information about use in OpenSim. Dynamic bimanual upper limb model implemented for OpenSim 3 software package.  View License
